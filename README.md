# tam-an-ai-app

## Overview
A Next.js (v13+) TypeScript web app that provides spiritual tools such as Tarot reading, meditation, dream interpretation and AI‑guided conversations. It features a **Hybrid Text‑to‑Speech (TTS) engine** (`sacredVoice.ts`) that combines a high‑quality Azure/Edge TTS API (Southern Vietnamese voice) with a fallback Web Speech Synthesis engine, and an ambient binaural 528 Hz soundscape.

## Prerequisites
- **Node.js** >= 18 (LTS) with npm
- **Python 3.11** (for the TTS API server)
- **uv** package manager (`pip install uv`)
- **Edge‑tts** Python library (`uv pip install edge‑tts`)
- Docker (optional, for containerised deployment)

## API – TTS Endpoint
`POST /api/tts` expects JSON `{ "text": "..." }` and returns an MP3 audio blob generated by the Python script `scripts/edge_tts.py` using the Southern Vietnamese voice (NamMinh/HoaiMy).
